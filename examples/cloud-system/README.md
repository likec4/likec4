# The Cloud System Architecture - LikeC4 example

This development example is based on [likec4/example-cloud-system](https://github.com/likec4/example-cloud-system).

Run `pnpm --filter @likec4/spa dev:single-project` from the repository root, then open the **View notes for elements and connections** diagram. Its `noteCards` view in [views.c4](views.c4) shows a view-scoped element note and a view-scoped connection note. Each note appears in a card with a dashed line to its target.
