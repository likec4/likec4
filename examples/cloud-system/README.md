# The Cloud System Architecture - LikeC4 example

This development example is based on [likec4/example-cloud-system](https://github.com/likec4/example-cloud-system).

Run `pnpm --filter @likec4/spa dev:single-project` from the repository root. Open the **View notes for elements and connections** diagram. The `noteCards` view in [views.c4](views.c4) shows an element note and a connection note. A dashed line connects each card to its target.
