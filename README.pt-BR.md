## O que é o LikeC4? Por que "Like"?

O LikeC4 é uma linguagem de modelagem para descrever arquiteturas de software e um conjunto de ferramentas para gerar diagramas a partir do modelo.

O LikeC4 é inspirado no [C4 Model](https://c4model.com/) e no [Structurizr DSL](https://github.com/structurizr/dsl), mas oferece flexibilidade adicional.
Você pode personalizar ou definir sua própria notação, tipos de elementos e qualquer quantidade de níveis aninhados no modelo de arquitetura.\
Tudo adaptado às suas necessidades.
