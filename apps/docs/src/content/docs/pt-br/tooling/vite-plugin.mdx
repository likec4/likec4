O plugin LikeC4 para Vite permite incorporar visões diretamente, sem etapas prévias de build ou geração.  
O plugin gera automaticamente o código necessário para renderizar visões na aplicação, com suporte a Hot Module Replacement (HMR).

Isso é útil na criação de documentação, tutoriais ou outras aplicações que precisem exibir diagramas.  
Não tem certeza de que esta é a abordagem certa? Consulte [Incorporar na sua aplicação](/tooling/embed/) para comparar as opções.

## Primeiros passos

<br />

<Steps>

1. ### Criar um projeto Vite

    Para começar, crie um projeto Vite com o template `react-ts`.

    <PackageManagers
       type="create"
       pkg="vite@latest"
       args="--template react-ts"
       comment="create a new project with {PKG}"
       pkgManagers={['npm', 'pnpm', 'yarn', 'bun']}
       frame="none"
      />
    <br />      
    <br />      

2. ### Instalar o LikeC4

    Adicione `likec4` como dependência de desenvolvimento. O plugin é executado durante o build, e o Vite
    empacota tudo o que a aplicação importa dos módulos virtuais, então `likec4` não é necessário em tempo de execução:
    
    <PackageManagers
       pkg="likec4"
       dev
       pkgManagers={['npm', 'pnpm', 'yarn', 'bun']}
       frame="none"
      />
    <br />
    <br />

3. ### Configurar o Vite
  
    Adicione o plugin LikeC4 à configuração do Vite:

    ```diff lang="ts"
    // vite.config.ts
    import { defineConfig } from 'vite'
    import react from '@vitejs/plugin-react'
    + import { LikeC4VitePlugin } from 'likec4/vite-plugin'

    export default defineConfig({
      plugins: [
        react(),
    +     LikeC4VitePlugin(),
      ],
    })
    ```
    <br />
    <br />

4. ### Adicionar referências de tipos

    Adicione as referências de tipos ao arquivo `vite-env.d.ts`  
    (ou crie um arquivo, como `src/likec4.d.ts`)

    ```diff lang="ts" {3}
    // src/vite-env.d.ts
    /// <reference types="vite/client" />
    /// <reference types="likec4/vite-plugin-modules" />
    ```

    Outra opção é adicionar a referência ao `tsconfig.json`:

    ```json
    // tsconfig.json
    {
      "compilerOptions": {
        "types": [
          "likec4/vite-plugin-modules"
        ]
      }
    }
    ```
    <br />
    <br />

5. ### Adicionar um modelo LikeC4

    Crie `src/tutorial.c4` e copie o modelo a seguir, retirado do tutorial:

    ```likec4 showLineNumbers copy collapse={14-57}
    //src/tutorial.c4
    // Tutorial - https://likec4.dev/tutorial/

    specification {
      element actor
      element system
      element component
    }

    model {
      customer = actor 'Customer' {
        description 'The regular customer of the system'
      }

      saas = system 'Our SaaS' {
        component ui 'Frontend' {
          description 'Nextjs application, hosted on Vercel'
          style {
            icon tech:nextjs
            shape browser
          }
        }
        component backend 'Backend Services' {
          description '
            Implements business logic
            and exposes as REST API
          '
        }

        // UI requests data from the Backend
        ui -> backend 'fetches via HTTPS'
      }

      // Customer uses the UI
      customer -> ui 'opens in browser'
      customer -> saas 'enjoys our product'
    }

    views {

      view index {
        title 'Landscape view'

        include *
      }

      view saas of saas {
        include *

        style * {
          opacity 25%
        }
        style customer {
          color muted
        }
      }

    }
    ```
    <br />
    <br />

6. ### Utilizar uma visão LikeC4 na aplicação

    Altere `src/main.tsx` e importe a visão LikeC4 do módulo `likec4:react`:

    ```tsx
    // src/main.tsx
    import { createRoot } from 'react-dom/client'
    import { LikeC4View } from 'likec4:react'

    createRoot(document.getElementById('root')!).render(
      <LikeC4View viewId='index' />
    )
    ```
    <br />
    <br />

7. ### Iniciar o servidor de desenvolvimento Vite

    <PackageManagers
       type="run"
       args="dev"
       pkgManagers={['npm', 'pnpm', 'yarn', 'bun']}
       frame="none"
      />

    Abra o navegador e acesse `http://localhost:5173/`.  
    O diagrama LikeC4 deverá aparecer renderizado na aplicação.

</Steps>

## Opções e módulos do plugin

### Opções

Opções que carregam o modelo LikeC4:

| Opção          | Descrição                                                                                         |
| -----------------| --------------------------------------------------------------------------------------------------- |
| `workspace`      | diretório dos arquivos-fonte (padrão: raiz do Vite) |
| `printErrors`    | se o modelo for inválido, os erros serão registrados no logger (padrão `true`) |
| <span style="text-wrap:nowrap">`throwIfInvalid`</span> | rejeita a Promise se o modelo for inválido (padrão `false`) |
| `graphviz`       | `wasm` (padrão) ou `binary`: utiliza os executáveis locais Graphviz ("dot") ou o WASM incluído    |
| `watch`          | monitora alterações nos arquivos-fonte no servidor de desenvolvimento (padrão `true`; o build nunca monitora) |
| `logLevel`       | `'trace'`, `'debug'`, `'info'`, `'warning'` (padrão) ou `'error'` |
| <span style="text-wrap:nowrap">`languageServices`</span> | um modelo já inicializado, veja [Utilização com a API](#utilização-com-a-api); não pode ser combinada com as opções acima |

Opções da aplicação, no nível superior das opções do plugin.
Observe a coluna "Lida por": apenas `customization` altera os componentes que você incorpora.

| Opção                | Lida por                                      | Descrição                                                                                            |
| -------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `customization`      | `likec4:react`, `likec4:webcomponents/*`      | caminho do arquivo de [personalização da interface](/tooling/customization/), relativo à raiz do Vite (experimental) |
| `title`              | `likec4:app-config`                           | título base das páginas da aplicação (padrão `'LikeC4'`)                                              |
| `theme`              | `likec4:app-config`                           | esquema de cores padrão, `'light'` ou `'dark'` (acompanha a preferência do sistema se não definido)   |
| `useHashHistory`     | `likec4:app-config`                           | navegação baseada em hash, por exemplo `/#/view` em vez de `/view` (padrão `false`)                   |
| `webcomponentPrefix` | `likec4:app-config`                           | prefixo dos Web Components, por exemplo `'c4'` gera `<c4-view/>` (padrão `'likec4'`)                  |

- `customization` se aplica aos componentes React de `likec4:react` e `likec4:react/<projeto>`,
  e aos Web Components de `likec4:webcomponents/<projeto>`, que renderizam esses componentes React.
- `title`, `theme`, `useHashHistory` e `webcomponentPrefix` apenas definem valores no módulo virtual `likec4:app-config`,
  lido pela aplicação LikeC4 (a servida por `likec4 start` e `likec4 build`).
  Elas não alteram os componentes de `likec4:react` nem de `likec4:webcomponents/<projeto>`
  (este registra o elemento com o nome que você passa), e o seu código só as vê se importar `likec4:app-config`.

```ts
// vite.config.ts
import react from '@vitejs/plugin-react'
import { LikeC4VitePlugin } from 'likec4/vite-plugin'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [
    LikeC4VitePlugin({
      customization: './likec4.customization.tsx',
    }),
    react(),
  ],
})
```

:::note
Essas opções ficavam aninhadas em `appConfig` (com `pageTitle` em vez de `title`).
`appConfig` ainda funciona, mas está obsoleta: mova as opções para o nível superior. As opções do nível superior prevalecem se ambas forem definidas.
:::

:::note
O plugin não lê a [configuração da aplicação](/tooling/app-config/) (`likec4.app.config.ts`).
Esse arquivo é da CLI do LikeC4; com o plugin, passe as opções como mostrado acima.
:::

### Workspaces com múltiplos projetos

Se você tiver [múltiplos projetos](/pt-br/config/multi-projects/) no workspace:

```tsx "project-a" "project-b"
// src/main.tsx

// where `project-a` and `project-b` are the names of your projects
import { LikeC4View as ProjectA_LikeC4View } from 'likec4:react/project-a'
import { LikeC4View as ProjectB_LikeC4View } from 'likec4:react/project-b'

const example = () => (
  <>
    <ProjectA_LikeC4View viewId='index' />
    <ProjectB_LikeC4View viewId='index' />
  </>
)
```
<br />

### Web Components

O módulo virtual `likec4:webcomponents/<projeto>`, específico do projeto, renderiza visões LikeC4 como elementos HTML personalizados,
sem componentes React no código da aplicação:

```ts
import { defineWebcomponent } from 'likec4:webcomponents/project-a'

defineWebcomponent('likec4-view-project-a') // depois use <likec4-view-project-a view-id="index">
```

Consulte [Web Components](/pt-br/tooling/web-components/#com-o-plugin-vite) para as regras de nomenclatura e os atributos disponíveis.

### Utilização com a API

Também é possível inicializar usando a [API do LikeC4](/pt-br/tooling/model-api/):

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { LikeC4 } from 'likec4'
import { LikeC4VitePlugin } from 'likec4/vite-plugin'

const { languageServices } = await LikeC4.fromSource(`
  specification {
    element system
    element user
  }
  model {
    customer = user 'Customer'
    cloud = system 'System'
  }
  views {
    view index {
      include *
    }
  }
`)

export default defineConfig({
  plugins: [
    react(),
    LikeC4VitePlugin({
      languageServices,
    }),
  ],
})
```
<br />

### Módulos virtuais

Outros módulos permitem acessar o modelo:

```tsx
// For multi-project workspaces
import { projects } from 'likec4:projects'

// Pick first one (default)
import { useLikeC4Views, useLikeC4View } from 'likec4:single-project'

// Project by name
import { useLikeC4Views, useLikeC4View } from 'likec4:model/project-a'

// Other modules
import { loadDotSources } from 'likec4:dot'
import { mmdSource } from 'likec4:mmd/project-a'
```

## Integração com frameworks

Veja exemplos de utilização do plugin com diferentes frameworks.

### Com Astro

Você também pode utilizar `LikeC4VitePlugin` com <a href="https://astro.build/" target='_blank'>Astro</a> e a ferramenta de documentação <a href="https://starlight.astro.build/" target='_blank'>Starlight</a>.  
Configure o Astro:

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import { LikeC4VitePlugin } from 'likec4/vite-plugin'

export default defineConfig({
  integrations: [
    starlight({
      title: 'Your architecture docs site',
    }),
  ],
  vite: {
    plugins: [
      LikeC4VitePlugin({}),
    ],
  },  
});
```

Para utilizar componentes React, primeiro envolva-os em componentes Astro:

```astro
// src/components/LikeC4View.astro
---
import { LikeC4View as ReactLikeC4View, type LikeC4ViewId } from 'likec4:react';
interface Props {
  viewId: LikeC4ViewId;
}
const { viewId } = Astro.props
---

<ReactLikeC4View
  viewId={viewId}
  controls={false}
  browser={{
    // options for likec4 browser
    enableFocusMode: false,
    enableSearch: false,
  }}
  client:only="react">
</ReactLikeC4View>
```

Depois, você poderá utilizá-los no Markdown:

```mdx
// src/content/docs/example.mdx
---
title: Welcome to my docs
---

import LikeC4View from '../../components/LikeC4View.astro';

## Introduction

This is an example of using LikeC4 in your documentation

<LikeC4View viewId="index" />

```
<br />

:::tip
Consulte o código-fonte para ver como os <a href="https://github.com/likec4/likec4/tree/main/apps/docs/src/components" target='_blank'>múltiplos projetos</a> LikeC4 são incorporados a este site.
:::

:::caution
Não se esqueça de [adicionar as referências de tipos](#adicionar-referências-de-tipos).  
No Astro, elas ficam no arquivo `src/env.d.ts`.
:::

### Com Next.js

Como o Next.js não utiliza Vite, é necessário recorrer ao [modo biblioteca](https://vite.dev/guide/build.html#library-mode):  
O Vite gerará uma biblioteca empacotada com diagramas LikeC4, que poderá ser importada na aplicação Next.js.  

Exporte tudo de `likec4:react`:

```tsx
// src/likec4/index.tsx
export * from 'likec4:react'
```
<br />

Configure o Vite:

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { LikeC4VitePlugin } from 'likec4/vite-plugin'

export default defineConfig({
  build: {
    // Build views to 'lib' directory
    outDir: 'lib',
    lib: {
      entry: 'src/likec4/index.tsx',
    },
    rollupOptions: {
      // make sure to externalize deps that shouldn't be bundled
      // to avoid code duplication
      external: [
        'react',
        'react-dom',
        'react/jsx-runtime',
        'react/jsx-dev-runtime',
        'react-dom/client',
      ],
    },
  },  
  plugins: [
    react(),
    LikeC4VitePlugin(),
  ],
})
```

Execute `vite build` e importe os arquivos gerados na aplicação Next.js:

```tsx
// pages/index.tsx
import { LikeC4View } from '../lib'

export default function Home() {
  return (
    <LikeC4View viewId="index" />
  )
}
```

Você pode executar `vite build --watch` para monitorar alterações nos arquivos-fonte LikeC4 e atualizar a compilação.
