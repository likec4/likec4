Esta action disponibiliza a [CLI do LikeC4](/pt-br/tooling/cli/) como uma GitHub Action.

<Aside type='tip'>
  O repositório [likec4/template](https://github.com/likec4/template) demonstra como publicar no GitHub Pages.

  Consulte também o guia [Publique seus diagramas](/pt-br/guides/publish/#publicar-no-github-pages) para um workflow completo.
</Aside>

## Como usar

### Gerar o site

```yaml
steps:
  - uses: actions/checkout@v7

  - name: ⚙️ build
    uses: likec4/actions@v1
    with:
      action: build
      path: src/likec4
      output: dist
      base: /baseurl/

  - name: upload artifacts
    uses: actions/upload-artifact@v7
    with:
      name: likec4
      path: dist
```

A action também copia `index.html` para `404.html` no diretório de saída, para o roteamento de aplicações de página única no GitHub Pages.

### Exportar diagramas para PNG

```yaml
steps:
  - name: export diagrams
    uses: likec4/actions@v1
    with:
      export: png
      path: src/likec4
      output: out/images
      use-dot-bin: 'true'
```

### Geração de código

```yaml
steps:
  - name: code generation
    uses: likec4/actions@v1
    with:
      codegen: react
      output: __generated__/likec4.jsx
```

## Parâmetros de entrada

| Nome                  | Descrição                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| `action`              | Ação a executar: `build`, `export` ou `codegen`                                                              |
| `export`              | Pode ser usado no lugar de `action: export`; `png` (padrão) ou `json`                                        |
| `codegen`             | Pode ser usado no lugar de `action: codegen`; `react` (padrão), `webcomponent`, `ts`, `dot`, `d2`, `mermaid` ou `mmd` (consulte [`likec4 gen`](/pt-br/tooling/cli/#gerar-likec4-gen)) |
| `path`                | Caminho dos arquivos-fonte LikeC4 no repositório; por padrão, a raiz                                          |
| `output`              | Diretório ou arquivo de saída                                                                                |
| `base`                | URL base personalizada para o site                                                                           |
| `use-dot-bin`         | Se `'true'`, utiliza o executável `dot` do Graphviz                                                          |
| `use-hash-history`    | Se `'true'`, o site usa navegação baseada em hash, por exemplo, `/#/view` em vez de `/view`                   |
| `webcomponent-prefix` | Prefixo dos web components gerados (`build` e `codegen: webcomponent`)                                       |
| `likec4-version`      | Versão do `likec4` a executar, por exemplo, `latest` (padrão: a versão incluída na action)                   |

> Todos os parâmetros são opcionais.  
> Por padrão, a action gera o site no diretório `dist`.
