O comando [`likec4 gen`](/pt-br/tooling/cli/#gerar-mermaid-dot-d2-e-plantuml) gera arquivos a partir do seu modelo.  
Você pode adicionar seus próprios geradores a ele.  
Geradores são funções, então defina-os em uma [configuração do projeto em TypeScript ou JavaScript](/pt-br/config/#configuração-typescript):

```ts
// likec4.config.ts
import { defineConfig } from 'likec4/config'

export default defineConfig({
  name: 'my-project',
  title: 'My Project',
  generators: {
    'hello': async ({ likec4model, ctx }) => {
      await ctx.write({
        path: 'hello.txt', // relative to the project folder
        content: `Project: ${likec4model.project.id}`,
      })
    },
  },
})
```

Agora você pode executar o gerador usando a [CLI](/pt-br/tooling/cli/):

```bash
likec4 gen hello
```

Em um workspace com [múltiplos projetos](/pt-br/config/multi-projects/), utilize:

```bash
likec4 gen hello --project my-project
# Other options
likec4 gen hello --project my-project --use-dot
```

## Parâmetros do gerador

O gerador recebe um objeto com dois campos:

- `likec4model`: o [modelo LikeC4](/pt-br/tooling/model-api/) do projeto, com as visões já diagramadas.
- `ctx`: o contexto do gerador:
  - `ctx.write({ path, content })` grava um arquivo. `path` é absoluto ou relativo à pasta do projeto; as pastas que faltam são criadas.
  - `ctx.locate(target)` retorna a localização no código-fonte de um elemento, relacionamento, visão ou elemento de implantação.
  - `ctx.project` contém o `id`, o `title` e a `folder` do projeto; `ctx.workspace` é a pasta do workspace.
  - `ctx.abort(reason)` interrompe o gerador.

## Geradores reutilizáveis

A função auxiliar `defineGenerators` também permite definir geradores reutilizáveis:

```ts
// shared_generators.ts
import { defineGenerators } from 'likec4/config'

export default defineGenerators({
  'hello': async ({ likec4model, ctx }) => {
    await ctx.write({
      path: 'hello.txt', // relative to the project folder
      content: `Project: ${likec4model.project.id}`,
    })
  },
})
```
Depois, você pode utilizá-los nos arquivos de configuração:

```ts
// likec4.config.ts
import { defineConfig } from 'likec4/config'
import generators from './shared_generators'

export default defineConfig({
  name: 'my-project',
  title: 'My Project',
  generators,
})
```

:::tip
Você também pode utilizar o pacote menor `@likec4/config`:

```ts
import { defineGenerators } from '@likec4/config'

export default defineGenerators({
  'hello': async ({ likec4model, ctx }) => {
    await ctx.write({
      path: 'hello.txt', // relative to the project folder
      content: `Project: ${likec4model.project.id}`,
    })
  },
})
```

:::
