O [Erode](https://erode.dev) utiliza inteligência artificial para analisar alterações no código em relação ao seu modelo de arquitetura LikeC4. Isso permite identificar dependências não declaradas e desvios estruturais durante a implementação e a revisão de código.

## Início rápido

O Erode pode ser integrado de três maneiras. Consulte a [documentação do Erode](https://erode.dev/docs/getting-started/) para obter instruções detalhadas de configuração.

### GitHub Actions

```yaml
- uses: erode-app/erode@0
```

### CLI

```shell
npx @erode-app/cli check
```

### Skill para Claude Code

O Erode também está disponível como uma skill para Claude Code. Consulte a [documentação](https://erode.dev/docs/getting-started/) para saber mais.
