## Início rápido

1. Certifique-se de que `likec4` e `graphviz` estejam disponíveis no ambiente de build.

2. Instale o plugin `mkdocs-likec4` usando `pip`:
  ```shell
  pip install mkdocs-likec4
  ```

3. Adicione o plugin ao arquivo `mkdocs.yml`:
  ```yaml
  plugins:
    - search
    - mkdocs-likec4
  ```

4. Comece a incorporar visões aos seus arquivos Markdown:
  ````markdown
  ```likec4-view
  <your-view-id>
  ```
  ````
