This action wraps [LikeC4 CLI](/tooling/cli) as a GitHub Action.

<Aside type='tip'>
  GitHub repository [likec4/template](https://github.com/likec4/template) demonstrates how to deploy to github pages.

  Also check [Deploying to GitHub Pages guide](/guides/deploy-github-pages/) for more details.
</Aside>

## Usage

### Build website

```yaml
steps:
  - uses: actions/checkout@v5

  - name: ⚙️ build
    uses: likec4/actions@v1
    with:
      action: build
      path: src/likec4
      output: dist
      base: /baseurl/

  - name: upload artifacts
    uses: actions/upload-artifact@v4
    with:
      name: likec4
      path: dist
```

The action also copies `index.html` to `404.html` in the output directory, for single-page app routing on GitHub Pages.

### Export diagrams to PNG

```yaml
steps:
  - name: export diagrams
    uses: likec4/actions@v1
    with:
      export: png
      path: src/likec4
      output: out/images
      use-dot-bin: 'true'
```

### Code generation

```yaml
steps:
  - name: code generation
    uses: likec4/actions@v1
    with:
      codegen: react
      output: __generated__/likec4.jsx
```

## Inputs

| Name                  | Description                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| `action`              | Action to perform: `build`, `export` or `codegen`                                                            |
| `export`              | Can be used instead of `action: export`; `png` (default) or `json`                                           |
| `codegen`             | Can be used instead of `action: codegen`; `react` (default), `webcomponent`, `ts`, `dot`, `d2`, `mermaid` or `mmd` (see [`likec4 gen`](/tooling/cli/#generate-likec4-gen)) |
| `path`                | Path in repository to likec4 sources, root otherwise                                                         |
| `output`              | Output directory/file                                                                                        |
| `base`                | Custom base URL for the website                                                                              |
| `use-dot-bin`         | If `'true'`, uses the `dot` binary of Graphviz                                                               |
| `use-hash-history`    | If `'true'`, the website uses hash-based navigation, e.g. `/#/view` instead of `/view`                        |
| `webcomponent-prefix` | Prefix for the generated web components (`build` and `codegen: webcomponent`)                                |
| `likec4-version`      | Version of `likec4` to run, e.g. `latest` (default is the version bundled with the action)                   |

> All inputs are optional.  
> By default the action builds a website to the `dist` directory.
