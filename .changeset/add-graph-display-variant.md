Add a "Graph" display variant for element views, alongside the existing "Diagram" view. It renders elements as compact circles with straight relationship lines, making it easier to see the topology of larger views. Switch between them with the new Diagram/Graph toggle in the navigation panel. In Graph mode, nodes are draggable and animated with a physics-based simulation (repulsion, springs along relationships, and a settle-back bounce), similar to Structurizr's Explore view.
