Element details put the description first: technology, links and metadata move to a sidebar that can be resized or hidden (the layout is remembered), and element kind and tags move to the footer of the card. The card remembers its size after you resize it and stays inside the window when dragged; double-click its title or the resize handle to reset its size and position.

Metadata shows every value at once. Click a key or a value to find other elements with the same metadata. Search supports `meta:key` and `meta:key=value` queries.

The style preset adds a `fieldLabel` text style for small all-caps field labels.
