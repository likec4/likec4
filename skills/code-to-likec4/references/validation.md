# Validation

Generated models must pass the LikeC4 validator:

```bash
npx -y likec4 validate --no-layout --json ./generated
# gate: .valid == true and .stats.filteredErrors == 0
```

- `--no-layout` checks syntax and model semantics without layout drift.
- `--file <path>` scopes results to edited files when iterating.
- Full CLI flags and output fields: `likec4-dsl` skill, `references/cli.md`.

Programmatic (optional `--check` flag on `emit.mjs`, needs `likec4` installed):

```ts
import { LikeC4 } from 'likec4'
const likec4 = await LikeC4.fromSource(dsl)
console.log(likec4.getErrors()) // must be []
```

Model-rule tests (`guides/validate-your-model` recipe, vitest):

```ts
import { LikeC4 } from 'likec4'
const likec4 = await LikeC4.fromWorkspace('./generated')
const model = likec4.computedModel()
test('every component has a technology', ({ expect }) => {
  for (const e of model.elementsWhere({ kind: 'component' })) {
    expect.soft(e.technology, `${e.id} has no technology`).toBeTruthy()
  }
})
```

Provenance check (generated files carry a header, no tag spam):

```bash
head -1 generated/spec.c4 generated/model.c4 generated/views.c4
# each: // Generated by code-to-likec4 — do not hand-edit. Regenerate via emit.mjs.
grep -c "#autogenerated" generated/*.c4  # expect 0
```

Notes: `toDSL`/`writeDSL` round-trip is lossy one-way generation, never a formatter. Minimum local gate without `likec4`: `emit.mjs` self-check (dup FQN / bad identifier).
